# Plan - Open or Shut

## Goal

Ship a free offline pretend door for kids, families, and seniors. The door can be open, shut, or locked. A locked door must be unlocked before it opens. An open door must be shut before it locks.

## Approach

1. App Store Connect has no rejected version waiting.
2. Build Open or Shut in Expo: one screen, one door, and a saved door.
3. Run the full simulator regression on the Release binary for build 1.
4. Take three native screenshots, then upload that binary and submit it.

## Why this app

Turn timers, picture lists, outing plans, dice, dinner answers, household places, tapped sentences, copy-the-line, room hunts, shape pairs, two-person poses, a week of walks, dressing choices, a shared orange, a window tally, a tea tray, and a kite string are already in this pipeline. Talking-stick apps and kids' turn timers are clocks. Leave-home checklists already cover "did I lock it." This one does not use a clock, a camera, a real lock, or a network. The family plays with one pretend door.
